# Project Brief: motion-transplant Landing Page

- **Product:** `motion-transplant` — an agentic coding skill & developer toolchain that captures real animations from any reference website via 4 layers of forensic instrumentation (DOMMatrix sampling, parameter extraction, curve fitting, slow-mo look), rebuilds them in an isolated sandbox, verifies parity with mathematical ground-truth curves, and transplants them cleanly into production code.
- **Target Audience:** Creative developers, design engineers, frontend craftsmen, agency directors, and AI agent builders who value high-craft motion, hate generic templates, and want to transplant award-winning animations into their sites with mathematical precision.
- **Feeling in 3 Seconds:** Precision laboratory meets raw street/editorial energy. Mechanical clarity, sharp contrast, zero generic fluff, mathematically undeniable craft.
- **Single Goal:** Compel creative engineers to install the skill, explore the docs, interact with the transplanted builds, and submit their own transplants to the showcase.
- **What it must never look like:** 
  - NO gradients (strictly forbidden by user).
  - NO purple/blue aurora blobs or glowing soft gradients.
  - NO generic 3-card grid with stock icons.
  - NO top-bar navigation (forbidden by dice constraint).
  - NO fake coordinates, fake timestamps, or decorative meaningless jargon.
- **Stack:** Pure HTML5, CSS3 Custom Properties (architectural monochrome + cadmium vermilion spot color), GSAP 3.12.5 + ScrollTrigger + CustomEase, Lenis 1.1.18 smooth scroll, Vanilla JS with live interactive telemetry widgets.
