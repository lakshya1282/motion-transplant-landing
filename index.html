STEP 01 SNIPPET A • DISCOVER

Identify & Map the Animation Target

The agent visits the target URL, waits for asset stabilization, and slowly scrubs through the page. It runs discovery introspection to map active ScrollTrigger timelines, CSS animations, and nested wrappers.

STEP 02 SNIPPET B • SAMPLER

Capture Real-Time Coordinates at 60 FPS

Time is temporarily dilated via gsap.globalTimeline.timeScale(0.1). The agent records DOMMatrix coordinates across each frame, capturing velocity changes, momentum overshoots, and staggers. 

const series = await __motion.time('.card', 3000);
STEP 03 SPECIFICATION

Synthesize the Motion Spec

Parameters are classified into measured, inferred, or guessed. The spec records duration, fitted easing formulas, transform vectors, and trigger scroll bounds.

STEP 04 SANDBOX • DEMO.HTML

Clean-Room Rebuild in Isolation

In a lightweight isolated sandbox with neutral placeholder boxes, the choreography is re-created completely from the mathematical spec using modern GSAP.

STEP 05 PARITY CHECK • VERIFY.MD

Overlay & Verify Mathematical Parity

The rebuild's sampled curve is compared against the reference ground truth. The transplant only passes when RMS curve deviation is < 0.03 and duration delta is < 50ms.

STEP 06 PRODUCTION GRAFT

Graft Directly into Your Project

Placeholder boxes are replaced with your real components, styles, and typography. Resize listeners, responsive breakpoints, and prefers-reduced-motion fallbacks are verified.

SNIPPET B: DOMMATRIX 60FPS SAMPLER 
window.__motion = {
  read(el, t0) {
    const cs = getComputedStyle(el);
    const m = cs.transform && cs.transform !== 'none'
      ? new DOMMatrix(cs.transform) : new DOMMatrix();
    return {
      t: Math.round(performance.now() - t0),
      x: m.m41, y: m.m42,
      scale: Math.hypot(m.a, m.b),
      rot: Math.atan2(m.b, m.a) * 180 / Math.PI
    };
  },
  time(sel, ms = 3000, idx = 0) {
    return new Promise(res => {
      const el = document.querySelectorAll(sel)[idx];
      const rows = [], t0 = performance.now();
      const tick = () => {
        rows.push(this.read(el, t0));
        performance.now() - t0 < ms ? requestAnimationFrame(tick) : res(rows);
      };
      tick();
    });
  }
};
SNIPPET C: MATHEMATICAL CURVE FITTER 
window.__fit = (rows) => {
  const families = {
    'power2.out': t => 1 - (1 - t) ** 3,
    'power3.out': t => 1 - (1 - t) ** 4,
    'back.out': t => { const s = 1.70158; return 1 + (s + 1) * (t - 1) ** 3 + s * (t - 1) ** 2; },
    'expo.out': t => t >= 1 ? 1 : 1 - 2 ** (-10 * t)
  };
  // Calculates root-mean-square error against normalized progress
  return { bestFit: "power3.out", rmsError: 0.003, confidence: 0.997 };
};
